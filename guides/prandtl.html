프란틀 수 (Prandtl Number)

공식에 값을 넣는 방법과 결과를 읽을 때 확인할 조건을 정리했습니다.

언제 쓰나요?

운동량이 퍼지는 속도와 열이 퍼지는 속도의 비를 나타냅니다. 유체의 열전달 문제에서 속도 경계층과 온도 경계층의 상대적인 성격을 이해하는 데 사용합니다.

공식과 입력값

Pr = μcₚ / k

μ는 점성 계수(Pa·s), cₚ는 정압 비열(J/kg·K), k는 열전도율(W/m·K)입니다. 같은 온도와 상태에서 평가한 유체 물성을 넣으세요. 동등한 식 Pr = ν/α에서는 ν가 운동 점성 계수, α가 열확산 계수입니다.

이 값으로 계산하기

직접 계산한 예제

가상의 물성값 μ = 0.001 Pa·s, cₚ = 4180 J/kg·K, k = 0.6 W/m·K를 대입하면 Pr = 0.001 × 4180 ÷ 0.6 ≈ 6.97입니다. 예시 값은 실제 설계 물성표를 대체하지 않습니다.

결과는 어떻게 읽나요?

Pr이 1보다 크면 이 정의에서는 운동량 확산율이 열확산율보다 큽니다. Pr은 유체 물성의 비이므로 이것만으로 대류 열전달 계수나 열량을 구할 수 없습니다.

적용할 때 주의할 점

온도에 따라 세 물성이 변합니다. 서로 다른 온도에서 가져온 μ, cₚ, k를 섞거나 점성 계수 μ와 운동 점성 계수 ν를 서로 바꾸어 넣지 마세요.

관련 무차원수

이 무차원수와 함께 계산하거나 비교하는 경우가 많은 수입니다.

  • 페클레 수 (Pe): 같은 L·v·물성이면 Pe = Re × Pr입니다.
  • 누셀트 수 (Nu): 대류 열전달 상관식은 흔히 Nu를 Re와 Pr의 함수로 줍니다.
  • 슈미트 수 (Sc): Sc는 Pr의 열확산 계수 α 자리에 물질 확산 계수 D를 넣은 지표입니다.
