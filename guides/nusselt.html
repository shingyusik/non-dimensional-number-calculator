누셀트 수 (Nusselt Number)

공식에 값을 넣는 방법과 결과를 읽을 때 확인할 조건을 정리했습니다.

언제 쓰나요?

표면과 유체 사이의 대류 열전달 계수를, 같은 길이 척도의 유체 열전도와 비교합니다. 서로 다른 유동 조건에서 열전달이 얼마나 강화되는지 비교할 때 씁니다.

공식과 입력값

Nu = hL / k

h는 대류 열전달 계수(W/m²·K), L은 해당 형상에서 정의한 특성 길이(m), k는 유체의 열전도율(W/m·K)입니다. h는 측정값이나 별도의 상관식에서 구해야 하며 이 계산기가 h를 예측하지는 않습니다.

이 값으로 계산하기

직접 계산한 예제

h = 50 W/m²·K, L = 0.1 m, k = 0.6 W/m·K라면 Nu = 50 × 0.1 ÷ 0.6 ≈ 8.33입니다. h와 k의 단위를 위와 같이 맞추면 길이와 온도 단위가 소거됩니다.

결과는 어떻게 읽나요?

같은 형상·길이 정의·유체 물성 조건을 비교할 때 Nu가 더 크면 대류 열전달 계수가 상대적으로 크다고 읽을 수 있습니다. 값 자체를 열유속이나 실제 전달 열량으로 혼동하지 마세요.

적용할 때 주의할 점

관의 지름, 평판의 진행 길이처럼 문제에 맞는 L을 선택해야 합니다. 평균 h로 계산한 평균 Nu와 위치별 h로 계산한 국소 Nu는 직접 같은 값으로 비교할 수 없습니다.

관련 무차원수

이 무차원수와 함께 계산하거나 비교하는 경우가 많은 수입니다.

  • 프란틀 수 (Pr): 대류 열전달 상관식은 흔히 Nu를 Re와 Pr의 함수로 줍니다.
  • 페클레 수 (Pe): Pe는 이송과 확산의 시간 비를 알려 주지만 열전달 계수 h를 주지는 않습니다.
  • 슈미트 수 (Sc): 물질전달 문제에서는 Sc가 열전달의 Pr 자리를 대신합니다.
