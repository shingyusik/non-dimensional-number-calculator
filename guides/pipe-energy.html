관의 압력손실: 보존법칙에서 포아죄유 해까지

같은 Re라도 관 길이가 달라지면 압력손실은 달라집니다. 질량·에너지 수지와 점성 해를 연결합니다.

내용·수치 검산: 2026-10-09

어떤 문제를 풀 수 있나요?

지름이 일정한 관에서 필요한 압력차를 알고 싶을 때, Re는 흐름의 상대적인 관성·점성을 알려 주지만 압력차 자체는 알려 주지 않습니다. 관 길이, 유량, 벽 조건을 함께 정해야 합니다. 이 글은 정상·비압축성 뉴턴 유체가 수평의 곧은 원형 관에서 완전히 발달한 층류를 이룬 경우를 다룹니다. 관은 강체이고 벽에서는 미끄럼이 없으며 점도는 일정하다고 가정합니다.

입구 구간, 굽힘, 밸브, 펌프, 높이 차이는 먼저 제외합니다. 따라서 아래 결과는 이 조건을 갖춘 구간의 손실이며 배관 전체의 요구 압력이 아닙니다. 유동 구간 확인에는 관 안지름을 특성 길이로 쓴 Re 계산기를 이용합니다.

정상 질량 보존은 ṁ = ρAv이고 밀도가 일정하면 Q = Av입니다. A = πD²/4를 사용하세요. 같은 유량에서 지름을 줄이면 속도도 변하므로 지름만 바꾼 Re 계산은 유량 고정 실험을 표현하지 않습니다.

점성 방정식을 적분하면 생기는 포물선

반지름 R = D/2로 두고 축 방향 운동량 방정식을 정리하면 0 = −dp/dx + μ(1/r)d/dr(r du/dr)입니다. 중심의 속도 기울기가 유한하고 u(R) = 0이라는 조건으로 두 번 적분합니다.

u(r) = Δp(R² − r²)/(4μℓ)
Q = 2π∫₀ᴿu(r)r dr = πR⁴Δp/(8μℓ)

단면 적분으로 v = Q/(πR²) = ΔpR²/(8μℓ)를 얻습니다. 중심 속도는 평균 속도의 두 배입니다. 이를 지름으로 다시 쓰면 Δp = 32μℓv/D²입니다. 이는 경험적인 난류 근사식이 아니라 위 가정에서의 점성 해입니다.

같은 손실을 에너지 수지로 읽기

일반적인 비압축성 구간의 수두 수지는 p₁/(ρg) + α₁v₁²/(2g) + z₁ + h펌프 = p₂/(ρg) + α₂v₂²/(2g) + z₂ + h터빈 + hL입니다. 여기서 α는 운동에너지 보정계수입니다. 완전히 발달한 층류의 포물선 분포에서는 α = 2이며, 균일 분포의 1을 무조건 쓰면 안 됩니다. 같은 지름·같은 분포·수평인 두 단면에서는 속도항과 높이항이 상쇄돼 hL = Δp/(ρg)가 됩니다.

Darcy 마찰계수 정의 Δp = fD(ℓ/D)(ρv²/2)와 위 해를 비교하면 fD = 64/Re입니다. Fanning 마찰계수는 fD/4이므로 두 표기법을 섞으면 손실이 네 배 달라집니다. 마찰이 있는 구간에 손실 없는 베르누이 식만 쓰면 같은 지름의 압력차를 0으로 잘못 예측하게 됩니다.

독립 계산 예제와 교차검산

설명용 상수 ρ = 1000 kg/m³, μ = 0.001 Pa·s, D = 0.01 m, ℓ = 2 m, v = 0.1 m/s, g = 9.81 m/s²를 사용합니다. 특정 온도의 물성표를 인용한 값이 아닙니다.

Re = 1000 × 0.1 × 0.01 / 0.001 = 1000

Q = π × 0.01² × 0.1 / 4 = 7.85398 × 10⁻⁶ m³/s

Δp = 32 × 0.001 × 2 × 0.1 / 0.01² = 64 Pa

fD = 0.064 → Δp = 0.064 × 200 × 5 = 64 Pa

hL = 64/(1000 × 9.81) = 0.006524 m

벽 전단응력 τw = ΔpD/(4ℓ) = 0.08 Pa; 구간 손실 동력 ΔpQ = 0.00050265 W

손실 동력은 이 구간에서 소산되는 기계적 동력입니다. 펌프 효율과 다른 구간을 포함하지 않으므로 펌프의 전력 소비량으로 읽지 마세요.

조건을 바꾸기 전에 확인할 것

동일한 D와 v에서 ℓ을 두 배로 하면 Re는 그대로이고 Δp는 두 배입니다. 동일한 Q와 ℓ에서 D를 절반으로 하면 Q식에서 Δp는 16배가 되지만 v는 4배, Re는 2배가 됩니다. 원래 층류였다는 이유만으로 새 조건에 같은 해를 적용하지 말고 Re와 발달 조건을 다시 확인하세요.

  • 관 지름을 mm에서 m로 변환했는지 확인합니다.
  • 입구·국부 손실과 고도 차이를 별도의 수지 항으로 더합니다.
  • 비뉴턴 유체, 거친 난류, 미끄럼 경계에는 이 해를 그대로 적용하지 않습니다.
