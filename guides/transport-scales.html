열·물질 확산과 경계층: Pr·Sc·Pe·Nu의 다른 역할

확산 길이의 유도, 이송 시간과의 비교, 열전달 계수의 입력 조건을 구분합니다.

내용·수치 검산: 2026-10-09

하나의 Re로는 온도와 농도 분포를 알 수 없습니다

같은 속도장 안에서도 운동량, 열, 용질은 서로 다른 속도로 확산됩니다. 뉴턴 유체, 일정한 물성, 반응·내부 발열이 없는 희석 용질과 열전달을 생각합니다. 확산은 등방적이라고 가정합니다. 속도와 물성이 온도나 농도에 크게 의존하면 이 단순 비교를 다시 검토해야 합니다.

여기서는 먼저 일정한 노출 시간 동안의 확산 척도를 계산합니다. 이후 벽을 따라 흐르는 경계층과 무엇이 다른지 구분합니다. 계산기에 입력할 α와 D는 각각 열확산 계수와 물질 확산 계수이며 같은 기호나 값을 쓰는 양이 아닙니다.

입력과 단위

세 확산 계수는 모두 m²/s 단위를 갖지만 다른 물리량입니다.
변수단위의미
ρ, μkg/m³, Pa·s밀도와 점성 계수
ν = μ/ρm²/s운동량 확산 계수
k, cₚW/(m·K), J/(kg·K)열전도율과 정압 비열
α = k/(ρcₚ)m²/s열확산 계수
Dm²/s해당 용질의 물질 확산 계수
v, L, tm/s, m, s대표 이송 속도, 길이, 시간
h, q″W/(m²·K), W/m²대류 열전달 계수와 면적당 열유속

물질 확산 계수의 D와 관 지름 D는 문헌에 따라 같은 글자를 사용합니다. 이 글에서는 D가 확산 계수입니다. 값을 입력할 때 변수 이름보다 단위를 먼저 확인하세요.

확산 방정식에서 길이 척도 얻기

정지 매질의 열확산 식 ∂T/∂t = α∂²T/∂y²를 ΔT/t ≈ αΔT/δ²로 크기 비교하면 δ ≈ √(αt)를 얻습니다. 운동량과 물질도 각각 δν ≈ √(νt), δD ≈ √(Dt)입니다. 이 식은 크기 척도이며 99% 경계층 두께의 정확한 상수까지 정하지 않습니다. 경계 조건과 두께 정의에 따라 계수는 달라집니다.

Pr = ν/α; Sc = ν/D
δν/δα ≈ √Pr; δν/δD ≈ √Sc

위 제곱근 비는 같은 노출 시간을 둔 순수 확산 비교입니다. 벽 근처 속도가 위치에 따라 달라지는 대류 경계층의 두께 비에 그대로 쓰면 안 됩니다. 실제 경계층에서는 속도 분포와 열·농도 경계 조건이 함께 중요합니다.

이송 시간과 연결한 검산 예제

설명용으로 ν = 10⁻⁶, α = 2×10⁻⁷, D = 10⁻⁹ m²/s, v = 0.2 m/s, L = 0.05 m를 둡니다. 예를 들어 ρ = 1000, μ = 0.001, k = 0.6, cₚ = 3000의 SI 입력으로 이 ν와 α를 만들 수 있습니다. 특정 유체의 실측 물성을 주장하는 예제가 아닙니다.

t이송 = L/v = 0.25 s

확산 척도: δν = 0.500 mm, δα = 0.2236 mm, δD = 0.01581 mm

Re = vL/ν = 10000; Pr = 5; Sc = 1000

열 Pe = vL/α = 50000 = Re × Pr

물질 Pe = vL/D = 10000000 = Re × Sc

δ/L ≈ 1/√Pe는 같은 시간 척도에서의 또 다른 검산입니다. 큰 Pe는 선택한 길이 전체의 확산보다 이송이 빠르다는 뜻입니다. 벽에 수직인 짧은 거리에 걸친 확산이 없어진다는 뜻이 아닙니다.

Nu는 주어진 h를 무차원화합니다

벽의 열유속을 q″ = h(T벽 − T기준)으로 정의하고 Fourier 법칙 q″ = −k(∂T/∂n)벽과 연결하면 h는 벽 온도 기울기를 포함합니다. 단순한 선형 온도층을 두께 δeff로 정의한 경우에만 h = k/δeff, Nu = hL/k = L/δeff라고 쓸 수 있습니다. 그 δeff를 앞의 순수 확산 길이나 99% 두께와 같은 값으로 놓지 마세요.

별도로 주어진 h = 120 W/(m²·K), k = 0.6 W/(m·K), L = 0.05 m라면 Nu = 10입니다. 온도차 20 K이면 q″ = 2400 W/m²입니다.

120이라는 h는 예제의 입력입니다. 위 Pe나 확산 척도에서 예측한 값이 아닙니다. 실제로 h를 추정하려면 형상, 층류·난류, 국소·평균 구분, 벽 온도·열유속 조건과 유효 범위가 명시된 해 또는 상관식이 필요합니다.

비교할 때 기록할 조건

  • 같은 길이·속도·물성으로 Re와 Pe를 비교합니다.
  • 열확산에는 α, 물질 확산에는 해당 용질의 D를 씁니다.
  • 확산 길이의 근삿값과 경계층 해의 두께 정의를 구분합니다.
  • 국소 h와 평균 h를 섞지 말고 기준 온도를 기록합니다.
  • Pr이나 Sc가 같아도 형상·벽 조건이 다르면 Nu 또는 물질 전달률은 달라질 수 있습니다.
