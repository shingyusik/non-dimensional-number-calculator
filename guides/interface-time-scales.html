표면장력과 비정상 유동: 힘의 비와 시간의 비 연결하기

We·Re·Fr·St를 같은 길이로 검산하고 곡률 압력과 모세관 시간의 의미를 구분합니다.

내용·수치 검산: 2026-10-09

작은 액적에서 어떤 힘을 비교하나요?

액적, 제트, 자유 표면을 생각할 때 관성·점성·중력뿐 아니라 표면장력이 필요합니다. 일정한 밀도와 점도, 일정한 계면장력을 가진 뉴턴 액체를 가정합니다. 계면활성제의 농도 구배, 증발, 접촉선 운동과 주변 기체의 영향은 이번 단순 척도 비교에 포함하지 않습니다.

이 글은 액적이 반드시 분열하는 속도나 공진 주파수를 예측하지 않습니다. 같은 현상에서 사용한 길이·상대 속도·주파수를 명시하고, 힘과 시간을 일관되게 비교하는 방법을 다룹니다.

주변 기체가 액적을 변형시키는 문제에서는 기체 밀도와 상대 속도로 정의한 We가 중요할 수 있습니다. 아래는 액체 내부 관성 척도의 예제이므로 그 기준을 바꾸지 않고 외부 공력 분열 기준과 비교하면 안 됩니다.

압력 척도로 무차원 비 유도하기

관성 압력 척도 ρv², 점성 응력 척도 μv/L, 곡률 압력 척도 σ/L, 중력 압력 척도 ρgL을 만듭니다. 각각의 비를 취하면 Re = ρvL/μ, We = ρv²L/σ, Bo = ρgL²/σ를 얻습니다. Fr = v/√(gL)이므로 Bo = We/Fr²입니다.

Ca = μv/σ = We/Re
Oh = μ/√(ρσL) = √We/Re
Bo = We/Fr²

Ca는 점성과 표면장력의 비이고 Oh는 물성과 길이만으로 관성·점성·표면장력을 묶습니다. 이런 조합은 검산에 도움이 되지만 표면의 형상이나 젖음 조건까지 정하지는 않습니다.

곡률 압력의 정확한 계수와 시간 척도

정지한 단일 구면 계면의 Young–Laplace 압력차는 Δp = 2σ/R = 4σ/L입니다. 위 σ/L은 크기 척도였으므로 정확한 구면 압력에 필요한 4를 구분해야 합니다. 두 계면을 가진 얇은 비눗방울에는 같은 단일 계면 식을 그대로 쓰지 않습니다.

거리 L을 움직이는 시간은 t이송 = L/v입니다. 계면 복원 압력과 관성의 크기를 ρL²/t² ≈ σ/L로 맞추면 t모세관 ≈ √(ρL³/σ)를 얻습니다. 따라서 We = (t모세관/t이송)²입니다. 이 t모세관은 선택한 길이에서 만든 척도이며 특정 모드의 정확한 액적 진동 주기가 아닙니다.

주기 T = 1/f이면 St = fL/v = t이송/T입니다. 주파수의 측정 대상이 무엇인지 기록해야 합니다. 같은 St라는 이유로 서로 다른 형상의 진동 모드가 같다고 할 수 없습니다.

한 입력으로 네 계산기와 조합 검산하기

설명용 입력 ρ = 1000 kg/m³, μ = 0.001 Pa·s, σ = 0.072 N/m, L = 0.002 m, v = 0.5 m/s, g = 9.81 m/s², f = 50 Hz를 둡니다. f는 주어진 가상 측정값이며 표면장력에서 예측한 주파수가 아닙니다.

Re = 1000; We = 6.94444; Fr = 3.56961; St = 0.2

Ca = 0.00694444; Oh = 0.00263523; Bo = 0.545

R = 0.001 m → 단일 구면의 Δp = 144 Pa

t이송 = 0.004 s; t모세관 ≈ 0.010541 s; T = 0.020 s

검산: (0.010541/0.004)² ≈ 6.94444이고 0.004/0.020 = 0.2입니다. 서로 다른 비를 같은 입력으로 계산했을 때 이 항등식이 맞지 않으면 지름·반지름 또는 밀도·속도 기준이 섞였는지 먼저 확인합니다.

작게 만들었을 때와 해석의 한계

물성과 v를 고정하고 L을 10분의 1로 만들면 Re와 We는 10분의 1, Bo는 100분의 1입니다. Fr는 √10배이고 t모세관은 10⁻³ᐟ²배입니다. 같은 속도에서 작은 형상은 상대적인 중력과 표면장력의 균형도 달라집니다. 이것이 크기만 축소한 실험이 모든 힘의 비를 보존하지 않는 이유입니다.

  • 분열 한계는 형상·주변 유체·변형 모드에 따라 달라져 We 하나로 확정하지 않습니다.
  • 정지 구면의 압력차를 움직이며 찌그러진 액적의 모든 지점에 적용하지 않습니다.
  • σ가 위치에 따라 달라지면 계면 접선 방향의 Marangoni 응력도 검토합니다.
  • 위 항등식은 같은 기준 물성과 길이로 정의했을 때만 검산에 쓸 수 있습니다.
