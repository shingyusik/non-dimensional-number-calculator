프란틀 수 계산기 (Pr)

점성 계수, 정압 비열, 열전도율로 프란틀 수를 계산합니다. 세 값은 같은 유체, 같은 온도에서 평가한 물성이어야 합니다.

값 입력과 계산

Pr = μcₚ / k

결과

입력값은 이 페이지 안에서 브라우저가 계산하며, 운영자가 따로 받거나 저장하지 않습니다.

Pr이 유체만으로 정해지는 이유

Pr = μcₚ/k는 운동 점성 계수 ν = μ/ρ를 열확산 계수 α = k/(ρcₚ)로 나눈 ν/α와 같습니다. 식에 속도나 길이가 없기 때문에, 같은 유체가 같은 온도·압력에 있다면 관 속을 흐르든 평판 위를 흐르든 Pr은 같습니다. 레이놀즈 수나 페클레 수가 흐름의 조건을 설명한다면, 프란틀 수는 유체 자체의 성격을 설명합니다.

변수와 SI 단위

프란틀 수 계산기의 입력 변수
기호의미SI 단위예제 값
μ유체의 점성 계수Pa·s0.001
cₚ정압 비열J/(kg·K)4180
k유체의 열전도율W/(m·K)0.6

단위에서 자주 틀리는 곳

  • 비열을 kJ/(kg·K)로 찾았다면 1000을 곱해 J/(kg·K)로 넣습니다. 4.18을 그대로 넣으면 Pr이 1000분의 1이 됩니다.
  • 점성 계수가 cP 단위라면 0.001을 곱해 Pa·s로 바꿉니다.
  • 운동 점성 계수 ν(m²/s)를 μ 칸에 넣지 마세요. 밀도만큼 차이가 납니다.
  • μ, cₚ, k를 서로 다른 온도의 표에서 가져오면 의미 없는 값이 나옵니다. 특히 액체의 점성 계수는 온도에 민감합니다.

값의 크기로 읽는 법

Pr이 1보다 크면 운동량이 열보다 빠르게 퍼집니다. 층류 경계층에서는 이때 속도 경계층이 온도 경계층보다 두꺼운 경향이 있고, Pr이 1보다 작으면 반대가 됩니다. 대략적인 크기를 보면 기체는 1 근처(공기는 약 0.7), 물은 상온에서 한 자릿수, 점성이 큰 기름은 수백 이상, 액체 금속은 1보다 훨씬 작습니다. 계산 결과가 이 범위에서 크게 벗어난다면 단위를 다시 확인하세요.

예제와 교차검산

예제는 μ = 0.001 Pa·s, cₚ = 4180 J/(kg·K), k = 0.6 W/(m·K)로 Pr ≈ 6.97입니다. 관 유동 노트에서는 cₚ = 4200으로 Pr = 7을 얻고, ν/α로 다시 계산해도 7이 나오는지 확인합니다. 같은 노트에서 Re = 2000과 곱한 14000이 페클레 수 계산 결과와 일치하는 것도 볼 수 있습니다.

Pr만으로 열전달 계수나 전달 열량을 구할 수는 없습니다. 대류 열전달 상관식에 Re와 함께 넣는 입력으로 쓰거나, 두 유체의 경계층 성격을 비교하는 데 씁니다.

관련 해설과 계산기

기본 해설

  • 프란틀 수 해설: 예제와 주의점

계산 노트

  • 관 유동에서 Re·Pr·Pe를 함께 검산하기: 같은 입력으로 세 계산기를 연결하고 Pe = Re × Pr이 맞는지 확인합니다.
  • 열·물질 확산과 경계층: Pr·Sc·Pe·Nu의 다른 역할: 확산 길이와 이송 시간을 비교하고 열전달 계수가 어디서 오는지 구분합니다.

관련 계산기

  • 페클레 수 (Pe): 같은 L·v·물성이면 Pe = Re × Pr입니다.
  • 누셀트 수 (Nu): 대류 열전달 상관식은 흔히 Nu를 Re와 Pr의 함수로 줍니다.
  • 슈미트 수 (Sc): Sc는 Pr의 열확산 계수 α 자리에 물질 확산 계수 D를 넣은 지표입니다.
