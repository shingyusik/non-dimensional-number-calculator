연락 창구

이 사이트의 연락 창구는 GitHub Issues 하나입니다. 이메일이나 전화로는 문의를 받지 않습니다. 이슈를 새로 만들려면 GitHub 계정으로 로그인해야 합니다. 개인이 운영하는 사이트라 답변 시점을 약속하기는 어렵지만, 올라온 이슈는 확인한 뒤 수정 여부와 함께 답을 남깁니다.

GitHub Issues는 누구나 볼 수 있는 공개 게시판입니다. 이름, 이메일 주소, 전화번호, 소속, 주소 같은 개인정보나 회사 내부 자료, 공개하면 안 되는 설계값을 적지 마세요. 실수로 올렸다면 본인이 직접 수정하거나 삭제할 수 있고, 운영자에게 숨김이나 삭제를 요청할 수도 있습니다.

받는 문의

  • 계산 결과가 공식이나 교재 값과 다를 때
  • 해설의 설명, 단위, 출처에 잘못이 있을 때
  • 깨진 링크, 화면이 깨지거나 버튼이 동작하지 않을 때
  • 한국어·영어 번역이 어색하거나 서로 다를 때
  • 추가했으면 하는 무차원수나 예제 제안
  • 개인정보처리방침에 관한 질문이나 요청

특정 설계에 대한 검토나 결과 보증은 제공하지 않습니다. 계산 결과의 사용 범위는 이용약관을 참고해 주세요.

오류를 제보할 때 적어 주실 내용

아래 내용이 있으면 같은 상황을 재현해 원인을 빨리 찾을 수 있습니다.

  1. 페이지 주소와 계산기 이름(예: /calculators/reynolds, 레이놀즈 수)
  2. 입력한 값과 각 값의 단위(화면에 넣은 숫자 그대로)
  3. 화면에 나온 결과
  4. 기대한 값과 그 근거(교재 이름과 쪽, 논문, 직접 계산한 과정 등)
  5. 화면 문제라면 사용한 브라우저와 기기 종류
제목: [레이놀즈 수] 결과가 교재 예제와 다름
페이지: /calculators/reynolds
입력: ρ = 998 kg/m³, v = 1.5 m/s, L = 0.05 m, μ = 0.001 Pa·s
화면 결과: (화면에 나온 값)
기대 값과 근거: (교재 이름·쪽 또는 계산 과정)

위 예시의 숫자는 형식을 보여 주기 위한 값입니다. 출처를 밝히기 어려운 기대값이라도 계산 과정을 적어 주시면 함께 확인할 수 있습니다.

재현하기 쉬운 제보와 어려운 제보

같은 문제라도 적힌 정보에 따라 확인에 걸리는 시간이 크게 달라집니다. 아래 두 제보는 같은 상황을 다르게 적은 가상의 예입니다.

  • 확인하기 어려운 제보: "레이놀즈 계산기가 틀린 것 같아요." 어떤 값을 넣었는지, 무엇과 비교했는지 알 수 없어 운영자가 같은 결과를 다시 만들 수 없습니다.
  • 바로 확인할 수 있는 제보: "/calculators/reynolds에 ρ = 998.2, v = 1.2, L = 25, μ = 0.001을 넣었더니 약 2.99 × 10⁷이 나왔습니다. 교재 예제는 약 3만입니다." 이 제보를 보면 지름 25 mm를 m로 바꾸지 않고 넣었다는 점을 곧바로 확인할 수 있습니다. 25 mm는 0.025 m이므로 Re는 약 29,946이 되어 교재 값과 맞습니다.

화면이 깨지거나 버튼이 동작하지 않는 문제라면 다음 정보가 도움이 됩니다. 브라우저 이름과 버전, 기기 종류와 화면 너비(예: 휴대전화 세로 화면), 어두운 테마나 영어 화면을 켰는지, 문제가 항상 생기는지 가끔 생기는지, 그리고 가능하면 브라우저 개발자 도구 콘솔에 나온 오류 문구를 적어 주세요. 화면 캡처를 첨부할 때는 주소 표시줄이나 다른 탭에 개인정보가 보이지 않는지 확인해 주세요.

제보를 받은 뒤 처리하는 순서

  1. 운영자가 이슈를 읽고 같은 입력으로 결과를 다시 계산해 봅니다.
  2. 재현에 필요한 정보가 부족하면 이슈 댓글로 질문합니다.
  3. 오류로 확인되면 페이지를 고치고, 수치 오류라면 검사 스크립트(tests/check_calculations.cjs)에 고친 값을 추가합니다. 수정한 커밋을 이슈에 연결하고 이슈를 닫습니다.
  4. 오류가 아니라고 판단한 경우(예: 비교한 교재가 다른 특성 길이를 쓴 경우)에도 그 이유를 댓글로 남깁니다.

개인이 시간을 내어 운영하므로 처리 시점은 정해져 있지 않습니다. 고친 내용은 사이트에 배포된 뒤 반영되며, 배포 전후의 변경 내역은 저장소의 커밋 기록에서 확인할 수 있습니다.

제보 전에 확인해 볼 것

결과가 예상과 다를 때 가장 흔한 원인은 단위입니다. 길이를 mm 그대로 넣지 않았는지, 점성 계수를 cP로 넣지 않았는지, 비열을 kJ 단위로 넣지 않았는지 먼저 확인해 주세요. 점성 계수 μ와 운동 점성 계수 ν를 바꿔 넣거나, 비교하는 교재와 다른 특성 길이를 쓴 경우에도 값이 달라집니다. 각 계산기 페이지의 ‘변수와 SI 단위’ 표와 단위 주의 항목에 자주 틀리는 환산을 정리해 두었습니다. 그래도 차이가 남는다면 제보해 주세요.

개인정보 관련 요청

개인정보의 열람, 정정, 삭제, 처리 정지에 관한 요청도 GitHub Issues로 받습니다. 요청에 개인정보가 필요하더라도 이슈 본문에는 요청 종류만 적어 주세요. 운영자가 이슈 댓글로 다음 절차를 안내합니다. 방문 통계와 광고에 쓰이는 정보는 Google과 Microsoft가 직접 처리하므로 각 회사의 설정 페이지에서 바로 조정할 수 있습니다. 자세한 내용은 개인정보처리방침에 있습니다.
